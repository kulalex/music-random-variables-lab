# Музыка и случайность — готовая дополнительная лабораторная КТвД

**Тема:** можно ли по танцевальности песни предугадать позитивность её звучания?

Две случайные величины из **одной** музыкальной базы Spotify:

- `danceability` — танцевальность трека, [0, 1];
- `valence` — позитивность звучания, [0, 1].

**Содержание:** доказательство стохастической природы, EDA и нормализация, зависимость (Спирмен + перестановки + χ²), математическая модель генератора, интерактивное приложение Marimo, сравнение синтетических и реальных наблюдений, автотесты и выводы для защиты.

## С чего начать

1. **[report.html](report.html)** — законченный отчёт с иллюстрациями; можно открыть двойным кликом (формулы MathJax требуют интернета).
2. **[REPORT.md](REPORT.md)** — то же исследование в Markdown, со всеми математическими формулами и списком источников.
3. **[marimo_app.py](marimo_app.py)** — интерактивный генератор. Это главный файл для демонстрации дизайнерского задания.
4. **[music_lab.ipynb](music_lab.ipynb)** — Jupyter-ноутбук с описанием, кодом и графиками.

## Запуск на Windows / Mac / Linux

Откройте терминал **внутри распакованной папки** и выполните:

```bash
python -m pip install -r requirements.txt
python -m marimo run marimo_app.py
```

Marimo выведет локальный адрес (обычно `http://localhost:2718`) — откройте его в браузере.

Для работы в редакторе с видимым кодом вместо `run` используйте:

```bash
python -m marimo edit marimo_app.py
```

Marimo реагирует на изменения выпадающего списка и ползунков автоматически: **жанр, число синтетических пар, seed и число квантильных групп**. Интернет и ключи Spotify для работы приложения не нужны.

Чтобы пересчитать весь анализ и получить свежие графики и `results.json`:

```bash
python analysis.py
```

Для просмотра классического ноутбука установите Jupyter Notebook (`python -m pip install notebook`) и откройте `music_lab.ipynb`.

## Контроль качества

```bash
python -m pytest -q
python -m marimo check marimo_app.py
```

Проверяются допустимый диапазон [0, 1], повторяемость при фиксированном seed, корректность обратного квантильного преобразования, соответствие средних и сохранение корреляции в условном генераторе.

## Суть результатов

- В исходном файле 114 000 строк; после дедупликации и проверки полей — **89 740 уникальных треков**.
- Случайная выборка — **12 000** уникальных треков без возвращения.
- **Спирмен ρ = 0,4803**, 95%-й бутстреп-интервал [0,4664; 0,4952].
- Перестановочное `p = 0,0005`, связь статистически обнаружена.
- Условный генератор на тестовом примере даёт **ρ = 0,4617**; независимый — **ρ = −0,0020**.
- Это не доказывает причинность и не позволяет безошибочно предсказать настроение отдельной песни.
